## 2026-10-25 · 接入 GitHub + 第一次配置"写入权限"

**今天做了什么**
- 注册 GitHub 账号，接入连接器，建了作品集仓库 `ai-study-portfolio`
- 第一次**手动上传文件**到 GitHub（commit），第一次用网页编辑器改文件、在审查下修掉两个真实问题（粘贴占位符、路径错误）
- 为了让 AI 助手能直接帮我更新仓库，生成了个人访问令牌（PAT），经历"读可以、写被拒"的排查，最终搞清两个关键点：
  1. 细粒度令牌在 git 地址里要用 `x-access-token` 当用户名，不是 GitHub 账号名
  2. 令牌的"作用仓库范围"必须包含目标仓库，否则即便权限全开也会被 403

**学到的（比操作本身更值钱）**
- **最小权限原则**：能力越大，越要给权限上锁。令牌只授权单仓库 + 限期，泄露损失被锁死在最小范围。
- **权限 = "能做什么" + "对谁做"**，两者缺一不可。
- 第一次完整走完"提交 → 审查 → 修复"的工程流程。

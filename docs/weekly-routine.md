# 我的学习作息系统 · Weekly Routine

> 背景：高二、物化生（全理）、最弱英语+化学、仅周日放假、工作日可控时间晚 7:30 后。
> 核心思路：**可控时间算着花**——把"该在学校做的"和"该在自主时间做的"彻底分开。

## 三条原则

1. **学校时间当主战场**：作业尽量校内清掉 70%，别全堆到晚上。
2. **碎片时间只背记**：课间/午休/排队，背英语单词、默写化学方程式——把大块的深度时间留给化学和数学。
3. **周日是三位一体**：复盘 + 补漏 + 真休息。

## 工作日节奏（晚 7:30 后）

| 时间 | 内容 | 说明 |
|------|------|------|
| 7:30–7:50 | 复盘 + 作业清债 | 错题 5 分钟归位，不拖 |
| **7:50–8:50** | **化学 60 分钟** | 弱科，放精力最好的头一小时，专啃推断/实验/计算 |
| **8:50–9:30** | **英语 40 分钟** | 弱科，单词 20 + 阅读精练 20，天天不断 |
| 9:30–10:10 | 轮换科 | 数学/物理/生物/语文轮着来，数学 2 次、物理 2 次保手感 |
| 10:10–10:30 | 语文微积累 + 看明天课表 | |
| 11:00 前 | 睡觉 | 守 6.5–7 小时，二批次逆袭的底线 |

> 若晚自习更晚，把化学/英语压缩成"最低保底线"版本，但**每天必须碰这两科**。

## 碎片时间用法

- 课间 / 午休 / 排队：背英语单词（每天 30+ 词）
- 默写化学方程式（离子式、氧化还原）
- 把大块深度时间留给化学和数学

## 周日安排（唯一完整自主日）

- 上午：补觉别过 10 点 → 化学专项突破 + 英语语法听力
- 下午：数学专题 + 物生巩固 + 预习下周
- 16:00 后：真放松
- 晚上：周复盘 + 列下周计划

## 弱科突破法

**化学**：方程式是"单词"，建知识网络图；实验题背模板；推断题练"突破口"思维。
**英语**：词汇为根基（每天不断）；阅读必须逐句翻译，别猜；完形找逻辑连接词。

## 执行保障

- 可打印周打卡表（每日打勾，连续性 > 强度）
- AI 助手每日 22:00 自动打卡提醒
- 状态差就做"10 分钟最小版"，出现了就算赢

# 提示词工程笔记 · Prompt Engineering

> 本笔记记录我从"会用 AI"迈向"写好提示词"的过程。核心结论：好提示词不是华丽的词，而是**把角色、任务、背景、格式、约束写清楚**。

## 一、黄金五要素

| 要素 | 作用 | 要不要 |
|------|------|--------|
| **角色 Role** | 给 AI 定人设和语气，比如"你是高二化学老师" | 专业/对口场景必加 |
| **任务 Task** | 让它具体做什么，不能模糊 | **必加**（没有任务 AI 不知干啥） |
| **背景 Context** | 我是谁、已知什么、卡在哪 | 想精准就加 |
| **格式 Format** | 输出成表格/分点/带例子 | 想好用就加 |
| **约束 Constraint** | 字数、语言、禁止项 | 按需加 |

> 心法：**角色 + 任务最不能省**；背景、格式、约束是"加分项"，越想结果精准越多加。

## 二、万能填空模板

> 你是 **[角色]** 。我要 **[任务]** ，背景是 **[我是谁 / 已知什么 / 卡在哪]** 。请按 **[格式]** 输出，要求 **[约束]** 。

括号填了就是一句高质量提示词。不需要文采，越具体越好。

## 三、案例：弱提示词 vs 强提示词（化学·原电池）

**❌ 弱提示词**
> 帮我讲一下原电池。

→ AI 可能讲得很泛，不照顾你的基础，听完还是懵。

**✅ 强提示词**
> 你是带过高考的化学老师。讲清「原电池原理」，我总搞混正负极、基础弱。用水果电池的生活例子，输出：1) 通俗讲解 2) 正负极判断口诀 3) 两道易错题加解析。中文，300 字内。

→ 角色对口 + 背景清晰 + 格式明确 + 约束具体，输出立刻好用十倍。

## 四、针对我的弱科（英语 / 化学）现成提示词

**英语（定语从句）**
> 你是高二英语老师。帮我用生活例子讲清「定语从句」，我语法薄弱、总在完形里丢分。输出：1) 通俗讲解 2) 3 道易错题 3) 答案与解析。中文讲解，300 字内。

**化学（原电池）**
> 你是带过高考的化学老师。讲清「原电池原理」，我总搞混正负极、基础弱。用水果电池的生活例子，输出：1) 通俗讲解 2) 正负极判断口诀 3) 两道易错题加解析。中文，300 字内。

## 五、提示词练习打卡模板

每次练习自己写一句提示词，再让 AI（小巴）批改：

```
日期：____
想解决的任务：____
我写的提示词：
    你是____，我要____，背景是____，请按____输出，要求____。
小巴批改：____
我的复盘（下次改哪）：____
```

> 提示：别直接丢需求给 AI，先自己写一句，再让我改到能直接用。练一次比看十遍都管用。

## 六、别忘了核实（底线）

AI 讲的内容可能出错（尤其化学方程式、语法规则）。写进作业或考试前，**回课本或问老师确认一遍**——这是不能省的一步。
